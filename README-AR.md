# منظومة أسامة فون — نسخة نشر قابلة للإعداد

## ماذا تحتوي؟
- واجهة زبائن عامة باللغة العربية.
- عرض المنتجات من Cloud Firestore، مع البحث والتصنيفات والأسعار والتوفر.
- طلب/استفسار مباشر عبر واتساب: +218924998194.
- لوحة إدارة منفصلة بتسجيل دخول Firebase Authentication بالبريد وكلمة المرور.
- قواعد Firestore تجعل القراءة العامة للمنتجات فقط، وتسمح بالتعديل لحسابات المسؤول التي لها سجل في `admins/{uid}`.
- إدارة أساسية للمنتجات (إضافة/تعديل/حذف/إظهار وإخفاء).

## مهم قبل النشر
هذه ملفات التطبيق، وليست دليلًا على أن الموقع منشور أو أن Firebase مهيأ. يجب إكمال الإعدادات التالية من حساب مالك المشروع، ثم الاختبار.

## إعداد Firebase
1. في Firebase Console افتح مشروعك ثم Project settings > Your apps > تطبيق الويب، وانسخ إعدادات SDK إلى `firebase-config.js`.
2. فعّل Authentication > Sign-in method > Email/Password.
3. أنشئ حساب المسؤول في Authentication > Users > Add user. استخدم بريدك أنت وكلمة مرور قوية وفريدة.
4. افتح Firestore Database وأنشئ قاعدة البيانات، ثم من Rules الصق محتوى `firestore.rules` وانشر القواعد.
5. انسخ UID لحساب المسؤول من Authentication > Users.
6. في Firestore Data أنشئ collection اسمها `admins` ثم document ID يساوي UID المسؤول. أضف حقلًا مثل `role` من النوع string وقيمته `admin`. لا تسمح للواجهة العامة بإنشاء مستندات admins؛ القواعد تمنع ذلك.
7. أضف مستندات منتجات في collection `products`، بحقول:
   - `name` string
   - `category` string (هواتف / إكسسوارات / قطع صيانة / خدمات / أخرى)
   - `price` number
   - `quantity` number
   - `imageUrl` string (اختياري، رابط HTTPS)
   - `description` string
   - `available` boolean
8. لا تستخدم مفاتيح Service Account في الموقع. إعدادات Web SDK ليست كلمة مرور، لكن لا ترفع أي مفاتيح إدارية أو رموز سرية إلى المستودع.
9. انشر الملفات عبر بيئة نشر تدعم Firebase Hosting. أوامر النشر تتطلب Node.js وFirebase CLI من كمبيوتر أو بيئة تطوير سحابية موثوقة؛ لا يمكن تنفيذها بمجرد تسجيل التطبيق من الهاتف.

## اختبار القبول قبل الإطلاق
- افتح الموقع في نافذة خاصة/جهاز آخر: تظهر المنتجات المتاحة والأسعار فقط.
- افتح `admin.html`: الزائر غير المسجل لا يرى لوحة الإدارة.
- جرّب تسجيل الدخول بحساب غير مسؤول: يجب أن تُرفض عمليات الكتابة.
- سجّل الدخول بحساب المسؤول: أضف منتجًا تجريبيًا ثم تحقق من ظهوره في الموقع العام.
- جرّب تعديل وحذف منتج، وتحقق من أن الزبون لا يستطيع تعديل البيانات.
- اختبر زر واتساب ورابط HTTPS.
- لا تدخل بيانات زبائن حقيقية حتى إكمال سياسة الخصوصية والنسخ الاحتياطي.
